# Branch-SQL-Query-
A SQL-based insurance branch management database designed for business analytics, featuring relational database design, advanced SQL queries, joins, aggregations, and reporting to support an interactive Branch Policy Dashboard.


🗄️ Project 1: Branch Policy Dashboard Database | SQL
📌 Project Overview

The Branch Policy Dashboard SQL Project is a relational database designed to manage and analyze insurance branch operations. The database stores information related to branches, customers, policies, premiums, account executives, product groups, solution groups, budgets, and revenue transactions. It serves as the backend data source for an interactive Excel dashboard, enabling efficient reporting and business analysis.

This project demonstrates SQL skills in database design, data manipulation, query optimization, joins, aggregations, and business reporting.

🎯 Business Objective

The objective of this project is to organize insurance business data into a structured relational database and generate meaningful business insights through SQL queries. The database supports branch performance analysis, revenue tracking, premium analysis, and sales performance reporting.
